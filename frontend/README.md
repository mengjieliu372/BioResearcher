# Frontend (React)

## Scripts

```bash
npm install
npm start
npm run build
```

## Notes
- API requests are proxied to backend `http://127.0.0.1:8000` in local dev.
- Login page defaults to account/password mode.
- QR panel uses local asset: `src/assets/login/getCode.png`.
- Programming step supports display package download (display files + R code + manifest).
